A Multi-Head Attention-Based TimesNet for Heat Production Planning Under Unknown Future Demands

2025.11

MDPI Energies · 제1저자

운영비용 5.93% 절감 · 정확도 3.01%p 향상

연구 배경

  • 지역난방시스템(DHS)의 기존 딥러닝 생산계획은 24시간 미래 수요·비용 예측값에 의존
  • 실제 환경에서는 예측오차가 존재해 안정적인 실시간 재계획에 한계

문제 정의

  • 미래 정보 없이 과거 24시간 이력 데이터만으로 즉각 재계획 가능한 AI 필요
  • 경제성과 설비 운용 안정성을 함께 고려하는 생산계획 모델 설계

모델 설계 (MATN)

  • MIP 모델로 180만 시간 분량의 최적 생산계획 훈련 데이터셋 구축
  • TimesNet Encoder로 다중 주기 시계열 패턴 추출
  • Transformer Decoder가 인코더 메모리를 참조해 자기회귀 방식으로 계획 생성

손실함수

  • Cross-Entropy 분류 손실 + 운영비용 손실 + 설비 Switching 손실 결합
  • 정확도뿐 아니라 실제 운용비용과 안정성을 반영한 Cost-Aware Loss

정량 성과

  • 기존 DNN 대비 총 운영비용 5.93% 절감, 예측 정확도 3.01%p 향상

보험 경험조정 분석 AX

2026.08 – 2026.10

예실차 원인분석과 리포팅 자동화

문제 정의

  • 6천만 건 이상 보험 계약 데이터에서 예실차가 커지는 계약군 탐색 필요
  • 계리사 수작업 분석의 탐지 속도·반복성·설명가능성 한계
  • AI 결과는 수치뿐 아니라 원인 후보와 근거 데이터까지 설명되어야 함

분석 방법론 — Custom Rule Mining

  • LightGBM의 Gain 기반 트리 분할 원리를 분석 목적에 맞게 직접 구현
  • Top-Down: 전체 모집단에서 영향 큰 조건을 단계적으로 분할
  • Bottom-Up: 고위험 세부 조합에서 조건을 완화하며 희귀 패턴 탐색
  • Dual Path: 두 경로의 점수·지지건수를 비교해 탐색 경로 전환

사후 검증

  • Rule 시계열: 월별 N·예실차 합계·평균·ASI·AMD로 지속성 확인
  • 동일계약 Bridge: 전월→당월 속성 변화와 예실차 변화의 동반 여부 분석
  • 일시적 이상과 반복적으로 악화되는 계약군을 구분

AX 연동

  • LLM/AI Agent로 결과 해석·점검사항 자동 생성
  • 자연어 질의, 재분석, 리포트 생성까지 이어지는 업무자동화 구조로 확장
